# S2 全局拼音规则

「规则管理」页面提供连续无声调拼音规则的新增、编辑、停用和删除。填写拼音和可选备注后保存，列表显示拼音及备注，无需规则名称。规则为空时不额外剔除。音节以空格分隔，ü 可写 v；不支持通配符、间隔或声调数字。拼音转换采用词组读音，不枚举所有多音字组合；同音表达也会被拦截。

配置保存在应用数据目录 `data/pinyin_rules.json`。草稿 V1、V2、V3 及整片优化 V3 共用这份配置，不按版本复制。下一次 S2 执行读取新快照；执行中的 S2 使用已读取快照。草稿管线记录 `pinyin-rules.snapshot.json`，整片优化将快照记录在 `S2.json`。命中句记录规则 ID、拼音及原文位置。

试匹配先选择已完成且拥有 S2 产物的任务，再选择一条要匹配的规则拼音，只测试选中规则。停用规则也可以试匹配，不改变其启用状态。读取全部子句，包括 S2 原先已剔除的子句。结果区分命中总数和原先通过、现在会被拦截的数量。测试只读，不重跑模型、不修改任务或成片。没有 S2 的成片重组和爆款学习任务不列入。

新剪辑版本必须复用 `agent_video.pinyin_rules` 的 `load_rules` / `match_text` / `apply_rules`，并在 S2 执行前读取一次全局快照。独立进程使用 `LIVECUT_PINYIN_RULES` 指向应用数据目录；不要创建版本私有拼音词表。直接 CLI 未设置时读取当前目录的 `data/pinyin_rules.json`。

## 随安装包分发

`npm run build:runtime` 会先运行 `desktop/export_rules.py`，导出当前全部规则（含备注、启用状态）到构建暂存目录，再通过 PyInstaller `--add-data` 放入安装包的 `defaults/pinyin_rules.json`。数据来源依次为显式 `LIVECUT_PINYIN_RULES` 文件、指定的桌面工作区/用户数据目录、桌面 `desktop.json` 记录的工作区，最后回退到源码目录 `data/pinyin_rules.json`。导出脚本打印实际来源和规则数量，便于确认使用的是当前规则。仅该规则文件随包分发，不复制数据库或其他运行数据。

新环境启动自动导入随包规则，无需手动填写。已有环境按拼音合并新规则，保留当地备注、启停状态及删除操作；初始化记录保存在 `data/pinyin_rules.seed-state.json`。源码运行指定独立数据目录时，也可从源码内的规则文件初始化。

安装后新增的规则保存在该电脑的工作区；下一次在该工作区构建安装包时带入新包。已生成的旧安装包不会自动更新，也不跨电脑实时同步。可单独用 `python desktop/export_rules.py --source <规则文件> --output <导出文件>` 验证或指定打包来源。
