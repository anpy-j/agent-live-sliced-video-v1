# LiveCut 0.2.1 剪映草稿修复

构建源码：`517b3af5d068ae44ab3bd6685556819d9bfe59b1`；功能修复提交：`7849506`。

原因为冻结的桌面后端仍使用 `sys.executable -m agent_video.jianying_crypto` 调用解密子进程。此时 executable 是后端应用，无法接受 Python 的 `-m` 参数，所有加密草稿解析失败，卡片的剪辑按钮因此禁用。

本版补上独立解密入口 `--jianying-decrypt`，开发版仍沿用 Python 模块入口。增加缓存版本使旧失败结果自动重建，并在卡片显示具体解析错误。原始剪映草稿只读，解密文件保存在临时目录。

## 验证

- 草稿列表、解密启动器及时间线相关测试：18 项通过，另有 2 个子测试通过。
- Windows 打包客户端在独立测试工作目录中复制旧失败缓存，读取本机 117 个剪映草稿；117 个剪辑按钮全部可用。未点击按钮提交生产剪辑任务。
- 打包客户端的人工编辑回归通过：新建、导入、分割、键盘撤销、重做、字幕、进度条、包内 FFmpeg 实际导出及退出。
- 安装目录检查未发现数据库、日志、.env、私钥或证书；无用户数据随包分发。
