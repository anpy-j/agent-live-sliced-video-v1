# 重复限制试匹配

「规则管理 → 重复限制」选择带有 S2 数据的已完成任务后，脚本对任务内原 S2 通过的全部子句做全局查重，不限制相隔距离。已剔除的子句不建立索引，不计次数，不作为首次出现，也不影响对象判断；仅在「全部子句」明细中保留展示。支持草稿管线及整片优化 V3，不调用 AI。

- 有效短语：以明确词表和结构提取「程度词 + 描述词」「主体 + 描述词」等表达，默认归一化后至少 4 字。例如第 1 句「这一件超级的难做」与第 20 句「超级难做」提取相同的「超级难做」，即使整句不同也归为一组。主体包括面料、版型、做工等；描述词包括难做、好看、保暖、显瘦等，完整词表见 `agent_video/repetition_rules.py`。不任意截取字串，不以「超级」「有没」作为重复表达。
- 完整语句：按句号、问号、感叹号、分号和换行分句，默认至少 4 字；完整语句归一化后相同才归组，逗号不分句。不降低全文相似度门槛。
- 颜色信息点：提取明确数量（「两个色」「两种颜色」「2个颜色」等），归一化为「可选颜色：2种」，按商品在全局分组，不要求措辞一致。五分裤、中裤、裤子等归为裤子；明确的其他商品及商品切换独立分组。省略商品的颜色句沿用此前明确颜色介绍的商品，搭配中提到的商品不切换这个参照。
- 颜色集合：保留本句识别到的颜色，只在识别数量与明确数量相等时记为完整集合。颜色语境里的「卡」可归到咖色，不将「看」猜改为咖色；完整集合冲突时分组，模糊表达不桥接多个冲突集合。第一版信息点仅检测颜色数量，不把「我现在穿的是黑色」等附加内容当作整句重复。
- 归一化：忽略标点、空白和英文大小写，只在已知结构中省略「的」「是」，并归一化同一程度词的口语强调。原文及字符位置不变。不会全局删除否定词；否定修饰的短语不提取为肯定表达。
- 对象保护：有效短语记录词表内明确出现的商品、颜色和部位，对象不同不合并。未指定对象的表达，只有全局候选中存在唯一明确对象时才加入该组；存在多个对象时不做跨对象推断。
- 次数：按原 S2 通过的不同子句数计，默认至少 2 条。单句「是不是超级超级好看」「有没有没买到我这个粉色羽绒服的」或同句重复多次都不会独自形成重复组。「可以水洗吗」若一条已因时长不足剔除、一条通过，只剩一条有效句，不构成重复。

页面可调整最少字数和最少出现子句数。信息点、有效短语、完整语句可单独测试或一起测试；字数门槛仅作用于短语和语句，信息点按其结构与数量匹配。结果按组显示比较表达、判定理由、全部出现位置（包括第一次），并在原句中高亮命中片段。颜色信息点额外显示本句颜色集合是否完整。下方子句明细可切换只看命中句或全部子句。三类统计可重叠；变更测试条件后需重新测试。

`GET /api/rules/repetition/jobs` 获取候选任务；`POST /api/rules/repetition/test` 接收 `job_id`、`kind`（`legacy` / `smart`）、`mode`（`all` / `fact` / `word` / `sentence`，`fact` 表示颜色信息点、`word` 表示有效短语）、`min_word_length`（2–32）、`min_sentence_length`（2–200）及 `min_count`（2–10）。未提供检测参数时使用默认值。返回 `groups`（重复组和全部位置）及 `rows`（子句明细）；`newly_rejected` 仅统计后续完整语句重复，不把局部短语或信息点重复等同于整句可删除。

试匹配不修改数据库任务、S2 文件或成片。旧 V1 S2 重复限制开关及自动剔除接入已移除，试匹配条件只用于只读检测。正式流程可选用 [语义归组插件](semantic-groups-plugin.md)，由 S4 从可替代候选中择优。算法在 `agent_video/repetition_rules.py` 中，后端测试用 `python -m unittest tests.test_repetition_rules tests.test_pinyin_rules`，页面验证用 `node tests/rules-ui.test.cjs`。

试匹配只索引原 S2 通过子句，已剔除的句子不能作为重复参照。该检测不接入自动 S2，不改变子句去留；基础粗筛原有的去重规则保持不变。

第一版仅覆盖显式词表、句式和完整语句归一化，不声称能判断任意语义等价。漏掉的表达可通过补充描述词、主体或句式扩展；「制作难度很高」与「超级难做」不会自动归为同组。

任务「【百搭公式】素材1013」只读实测：原 S2 通过的 ID 6「五分裤两个色,一个黑,然后一个看。」、ID 41「我们给大家两个颜色我现在穿的是黑色」、ID 83「褲子黑跟卡兩個色」归为裤子颜色数量的同一组；ID 110 的皮衣两色不混入。保留 ASR 原文，不修改 S2 文件。
