# 独立视频后处理模块

2026-10-11，源码开发版。入口：左侧「视频后处理」。

## 使用流程

1. 人工在剪映完成剪辑，导出到 `D:\切片\袁艺灵\待完成`。
2. 在「视频后处理」批量导入这些视频，通过四个标签页分别选择画中画、动态进度条、边角贴纸、音频。
3. 输出目录设置为 `D:\切片\袁艺灵\完成版`，提交处理队列。
4. 完成后在页面播放成片、打开所在目录。原文件保留，失败任务显示原因，可重新提交。

当前版本手动批量导入，尚未实现自动监控目录。可单独使用，不要求视频来自 LiveCut，也不需要打开人工编辑器或关联剪映草稿。资源、任务和设置保存在自己的 `data/postprocess`，不改动 V1 任务和人工编辑项目。

## 可选效果

| 效果 | 当前功能 |
| --- | --- |
| 画中画 | 选择视频素材文件夹、图片素材文件夹并扫描。每条成片各随机选一个，全屏滤色叠加，两层透明度均为 1%；图片从 0° 持续旋转到 999°，短视频循环，素材音频静音。 |
| 底部动态进度条 | 跳动爱心、漂浮爱心、闪耀星光、游走小星星。前三种随进度逐渐出现、按比例重复铺满；游走小星星只有一颗闪烁星星，按整条视频进度从最左走到最右。高度可调，预留底部空间保留画面内容。 |
| 四角贴纸 | 内置闪烁星星、呼吸光环动态 GIF；可导入自己的图片/GIF。露出支持 0.1%、0.2% 等小数，默认 0.2%，0 表示不露出。 |
| 音频 | 导入自己的音乐、调整原声和配乐音量、循环铺满视频，配乐有短淡入淡出。 |
| AI 配乐 | 连接 ACE-Step 异步服务，选择风格、提示词、时长和 BPM，生成后加入音乐库，先试听再选用。 |

四角贴纸露出的部分仍会覆盖极小边角；如要求画面内完全没有覆盖，关闭贴纸。极小比例最终受成片像素精度限制。1% 透明度仍会轻微改变像素，是否肉眼可见取决于素材；不需要时可关闭画中画。视频音频都会重新编码，不保证平台判重结果。

页面显示源视频与视觉效果预览，音乐单独试听；最终混音和合成以导出成片为准。画中画预览用两个文件夹中的第一组素材，导出时每条成片随机组合，具体素材 ID 固定在任务快照。资源、任务历史和上次提交的方案会保留；待处理源视频列表刷新后需要重新导入。

文件夹扫描读取文件夹第一层，支持最多 500 个候选文件。每次新增/更换素材后重新扫描；当前没有监控文件夹自动刷新。无可用视频或图片时不会提交缺少素材的画中画任务。旋转图片先扩大到覆盖画面所需大小，再旋转、居中裁切，避免旋转过程中出现空白边角。

AI 配乐下载后先检查实际解码时长和半秒分段音量，再加入素材库。全程近静音、末尾连续至少 2 秒近静音、其他连续至少 3 秒近静音、时长偏差超过 0.5 秒时显示失败原因，不自动入库。检测阈值综合绝对音量与整首的相对音量，并分别测量声道避免反相立体声被误判；这是音量连续性检查，音乐效果仍需试听。失败的原始生成文件与结果元数据保留用于检查，本地导入的音乐不受此生成检测影响。

## 资源从哪里来

- **画中画**：来自用户提供的两个本地文件夹。
- **动态进度条**：四个本地生成的透明动画模板，按参考图的爱心/星光方向实现，不是复制截图内的商业素材。
- **贴纸**：内置两种透明动态 GIF 由本地算法生成，动画是逐帧变化的。导入的 GIF 也会循环播放。
- **音乐**：用户本地文件，或 ACE-Step 生成的 WAV。资源不会从剪映商业素材库自动下载。

## 本机 CPU 音乐环境

2026-10-11 已安装独立 Python 3.12 环境，PyTorch `2.10.0+cpu`，不占用 V1 的 Python 依赖；只使用 CPU，关闭辅助语言模型。ACE-Step 源码固定在 `ca1e85fe9430179831e6bc6be790c332190a3866`。

- 环境：`.runtime/ace-cpu`
- 源码及模型：`.runtime/ace-step`，模型在 `checkpoints`。
- 默认服务：`http://127.0.0.1:8001`
- 页面「启动本机 CPU 服务」启动后台进程，首次生成请求才下载/加载模型。
- 页面可查看状态及日志；LiveCut 关闭会停止自己启动的服务，已有外部服务保持运行。
- 音乐生成完成后可点「停止服务释放内存」，只停止本应用启动的服务，音乐素材保留；生成中不允许停止。当前 CPU 模型占用较多内存，本机实测空闲服务约占 14 GB，同时运行 V1 导出可能触发内存保护。
- 默认先试 10 秒纯音乐。首次模型下载、CPU 加载和生成可能持续较长时间；服务健康不等于模型已加载或已生成音乐。
- 音乐任务可以查看完成/失败状态；目前不支持取消服务端音乐生成任务。视频处理队列支持取消。

重新安装环境：在仓库根目录用 **Python 3.12** 执行：

```powershell
py -3.12 desktop/setup-ace-cpu.py
```

安装脚本只安装环境，不立即下载权重。其他安装位置可用 `LIVECUT_ACESTEP_ROOT` 和 `LIVECUT_ACESTEP_PYTHON` 环境变量指定。服务地址可在模块中修改；本机启动按钮只接受本地 HTTP 地址。服务鉴权密钥通过 `ACESTEP_API_KEY` 环境变量配置。

官方项目：[ACE-Step 1.5](https://github.com/ace-step/ACE-Step-1.5)。首次 10 秒样本 `.runtime/ace-cpu-smoke.wav` 经用户试听发现后半段近静音，不应作为有效配乐。已重新生成 `.runtime/ace-cpu-verified.wav`，生成约 42 秒，半秒分段检测后半段正常，仅末尾约 0.5 秒近静音。音质需试听，真实 CPU 试验结果另记在 [AI 音乐生成候选评估](AI音乐生成候选评估.md)。

## 开发版启动及验证

### 文件夹自动处理

在“文件夹自动处理”中选择监控目录（例如 `D:\切片\袁艺灵\待完成`），自动输出目录默认 `D:\切片\袁艺灵\完成版`。先在画中画模块填写两个素材文件夹，在进度条和贴纸模块选择样式，然后点击“启动自动监控”。自动模式强制启用画中画、进度条、贴纸，沿用当前高度、样式、露出比例和原声音量；不添加配乐。参数在启动时保存快照，编辑效果后再次点击“更新设置并继续监控”生效。自动输出目录独立于手动导出目录。

每 3 秒扫描监控目录的第一层 MP4、MOV、MKV、WEBM、AVI 文件，观察文件大小与修改时间稳定至少 10 秒，再验证和提交导出。输入视频完整内容 SHA-256 用于跳过已登记的视频，改名或复制不会重复提交；修改原视频内容会作为新输入。稳定时间只能减少读到未完成文件的概率；长时间暂停的写入仍可能被误判，建议外部程序先导出为非视频扩展名的临时文件，完成后再改名放入监控目录。

每条新视频随机预留一个未使用的画中画视频和一张未使用图片，素材内容 SHA-256 与输入、选用素材路径、参数、导出任务和输出路径保存在后处理 SQLite 中。每个素材各自只用于一个自动输入任务，不仅仅是组合不重复；相同素材改名或复制也不能再次分配。100 个不同视频和 100 张不同图片最多支持 100 条自动任务。素材耗尽时等待用户补充新的不同内容文件，补充后自动恢复，不自动重置记录。

原视频保留；已登记的失败任务不反复自动提交，有预留素材的任务可在“自动处理与素材使用记录”中点击“使用原素材重试”，不会消耗另一组素材。关闭客户端后监控暂停运行；重新启动客户端自动恢复之前启用的监控，即使尚未打开后处理页面。停止监控只停止新输入，已提交的导出继续执行，可在处理队列单独取消。监控目录、成片目录和素材目录不能互相嵌套，避免输出被再次处理。

验证：`tests/test_postprocess_watcher.py` 覆盖真实自动导出、原文件保留、画中画/进度条/贴纸快照、两类素材各自不重复、复制素材与输入去重、耗尽等待、补充恢复、重启记录、失败沿用素材重试、文件稳定与暂停及目录重叠限制。页面自动化覆盖选择目录、启用自动监控、真实成片、使用记录、刷新恢复设置及停止。

### 批量生成画中画素材

入口：视频后处理 → 画中画 → 展开“批量生成画中画素材”。默认生成 100 个无声 MP4 视频与 100 张 PNG 图片，视频时长 10 秒、30 fps、720 × 1280。可调整数量（各 0–100，至少一种非零）、时长（2–30 秒）和分辨率（720 × 1280 或更快的 360 × 640）。无需联网或 AI 模型。

选择保存目录后点击“开始生成素材”。五种程序绘制风格为光点、波纹、几何线条、星光、柔和光斑，每个文件使用独立种子与构图；视频通过周期性平移和缩放实现循环运动。每批在独立子目录内创建“视频”“图片”两个文件夹，保留素材来源、种子和完成状态的 `manifest.json`，不覆盖已有批次。

生成在后台串行执行，页面显示当前文件、两类完成数量和进度。支持取消，取消及关闭客户端时停止该批生成并保留已经完成的文件；程序重新启动后中断的批次标为失败，不自动续跑。素材任务记录与素材库持久保存。已完成素材自动登记到素材库；点击“使用这批素材”才替换当前两个素材池并启用画中画，设置会保存。也可以手动扫描这两个输出文件夹。

后端验证：`python -m pytest tests/test_postprocess_materials.py tests/test_postprocess.py -q`。实际生成小批次并检查尺寸、时长、无声、不同文件内容、运动变化、取消保留、并发限制及重启记录；页面验证包含默认 100+100 参数、真实生成、载入素材及后处理导出。未预生成 100+100 个文件，用户选择目录后执行。

