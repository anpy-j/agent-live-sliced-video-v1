# 独立视频后处理模块

2026-10-11，源码开发版。入口：左侧「视频后处理」。

## 使用流程

1. 人工在剪映完成剪辑，导出到 `D:\切片\袁艺灵\待完成`。
2. 在「视频后处理」批量导入这些视频，选择需要的效果和音乐。
3. 输出目录设置为 `D:\切片\袁艺灵\完成版`，提交处理队列。
4. 完成后在页面播放成片、打开所在目录。原文件保留，失败任务显示原因，可重新提交。

当前版本手动批量导入，尚未实现自动监控目录。可单独使用，不要求视频来自 LiveCut，也不需要打开人工编辑器或关联剪映草稿。资源、任务和设置保存在自己的 `data/postprocess`，不改动 V1 任务和人工编辑项目。

## 可选效果

| 效果 | 当前功能 |
| --- | --- |
| 底部进度条 | 纯色、条纹、高光；颜色、高度可选，随视频进度增长。画面整体轻微压缩后预留底部空间，保留画面内容。 |
| 画中画 | 导入图片或视频，选择旋转角度和透明度；默认 1%。可生成本地抽象纹理图片。 |
| 四角贴纸 | 内置闪烁星星、呼吸光环动态 GIF；可导入自己的图片/GIF。默认只露出少量边缘，可调露出比例。 |
| 音频 | 导入自己的音乐、调整原声和配乐音量、循环铺满视频，配乐有短淡入淡出。 |
| AI 配乐 | 连接 ACE-Step 异步服务，选择风格、提示词、时长和 BPM，生成后加入音乐库，先试听再选用。 |

四角贴纸露出的部分仍会覆盖极小边角；如要求画面内完全没有覆盖，关闭贴纸。1% 透明度仍会轻微改变像素，是否肉眼可见取决于素材；可自行调到 0。视频音频都会重新编码，不保证平台判重结果。

页面显示源视频与视觉效果预览，音乐单独试听；最终混音和合成以导出成片为准。资源和任务历史会保留；当前表单的效果选择、待处理源视频列表刷新后需要重新选。

## 资源从哪里来

- **画中画**：支持用户提供图片/视频；内置抽象纹理由本地算法生成，不依赖外部图库或 AI 服务。
- **贴纸**：内置两种透明动态 GIF 由本地算法生成，动画是逐帧变化的。导入的 GIF 也会循环播放。
- **音乐**：用户本地文件，或 ACE-Step 生成的 WAV。资源不会从剪映商业素材库自动下载。

## 本机 CPU 音乐环境

2026-10-11 已安装独立 Python 3.12 环境，PyTorch `2.10.0+cpu`，不占用 V1 的 Python 依赖；只使用 CPU，关闭辅助语言模型。ACE-Step 源码固定在 `ca1e85fe9430179831e6bc6be790c332190a3866`。

- 环境：`.runtime/ace-cpu`
- 源码及模型：`.runtime/ace-step`，模型在 `checkpoints`。
- 默认服务：`http://127.0.0.1:8001`
- 页面「启动本机 CPU 服务」启动后台进程，首次生成请求才下载/加载模型。
- 页面可查看状态及日志；LiveCut 关闭会停止自己启动的服务，已有外部服务保持运行。
- 默认先试 10 秒纯音乐。首次模型下载、CPU 加载和生成可能持续较长时间；服务健康不等于模型已加载或已生成音乐。
- 音乐任务可以查看完成/失败状态；目前不支持取消服务端音乐生成任务。视频处理队列支持取消。

重新安装环境：在仓库根目录用 **Python 3.12** 执行：

```powershell
py -3.12 desktop/setup-ace-cpu.py
```

安装脚本只安装环境，不立即下载权重。其他安装位置可用 `LIVECUT_ACESTEP_ROOT` 和 `LIVECUT_ACESTEP_PYTHON` 环境变量指定。服务地址可在模块中修改；本机启动按钮只接受本地 HTTP 地址。服务鉴权密钥通过 `ACESTEP_API_KEY` 环境变量配置。

官方项目：[ACE-Step 1.5](https://github.com/ace-step/ACE-Step-1.5)。独立模块完成并不代表这台核显电脑已验证为可稳定生产配乐；真实 CPU 试验结果另记在 [AI 音乐生成候选评估](AI音乐生成候选评估.md)。
