# 简略版剪辑器：功能与资源方案

日期：2026-10-10。阶段：研究与范围设计，尚未实现编辑器。本文件中的数量为建议起步范围，不是已有功能或素材数量。

## 目标与流程

面向 V1 粗筛结果的人工精剪，支持一个项目多个独立时间线、每条时间线多轨道，以及字幕、音乐、贴纸、基础转场和效果。人工提交导出后自动套用后处理模板，检查后写入完成版。保留待完成目录作为剪映导出的兼容入口。

V1 粗筛 → 待剪列表 → 创建/领取编辑项目 → 多轨编辑与字幕校正 → 完成并导出 → 后台渲染与检查 → 完成版。

项目保存素材引用与剪辑记录，不破坏原视频。一个素材可用于多个项目/时间线；领取状态是业务状态，不能等同成片完成。导出快照冻结时间线和资源版本，导出期间继续编辑不会改变已排队任务。

## 功能范围

| 模块 | 首个可用版本 | 后续扩展 |
| --- | --- | --- |
| 项目 | 多时间线新建/复制/重命名/独立保存；关联 V1 来源 | 项目模板与批量创建 |
| 多轨 | 视频、音频、图片贴纸、字幕；隐藏/静音/锁定；音视频关联 | 复杂嵌套序列、调整层 |
| 剪辑 | 分割、裁剪、拖动排序、复制粘贴、普通删除与波纹删除、吸附 | 复杂修剪模式 |
| 预览 | 播放/定位/逐帧、波形、缩略图、缩放、基础合成 | 更多效果实时预览 |
| 保护 | 撤销重做、自动保存、恢复、素材缺失提示与重新定位 | 历史版本管理 |
| 字幕 | 自动识别/导入、校正、拆合句、调时间、模板、关键词强调、跟随剪辑 | 更多逐字和复杂图文动画 |
| 音频 | 本地音乐库、试听、音量、淡入淡出、裁剪循环、人声与原声切换 | 自动压低配乐、独立人声分离模型 |
| 贴纸 | PNG/WebP；导入动态素材并标准化；位置/尺寸/旋转/不透明度/时段 | 更多动画格式和关键帧 |
| 转场 | 建议起步 5–8 种，调时长并预览 | 自定义遮罩和复杂转场 |
| 特效 | 建议起步 5–10 种基础调节与动画 | 插件、复杂 GPU 特效 |
| 导出 | 当前/批量时间线、模板后处理、进度/取消/重试、完整性检查 | 更多编码与画幅预设 |

字幕是核心必需功能。第一版应有基本字幕样式和校正工作流，不能仅交付自动转写文字。音乐与贴纸作为必需模块保留，资源数量和动画复杂度分阶段扩充。人声分离功能保留规划，但先解决已处理音频来源与映射问题。

## 时间线与同步设计

- 多时间线：多个成片标签；多轨道：同一成片内的叠加层，两者分别实现。
- 项目时间用整数帧/有理时间与音频采样位置管理，避免累积浮点误差；不同帧率素材映射到输出时钟。
- 视频和原声关联，可联动分割移动，也可解除关联。
- 普通删除保留空隙；波纹删除移除时段并按明确规则移动相关轨道。锁定轨道/跨边界素材遇到冲突时提示，不能悄悄错位。
- 转场需要重叠或源素材余量，并明确总时长变化、字幕/音乐映射和声音交叉淡化规则。不能用截掉口播来凑转场长度。
- 字幕既记录成片时间，也保留音频片段与来源时间关联；切分、删除、移动、变速时更新。跨切点字幕需要拆分、重新断句或提示复核。
- 优先利用可信的原素材字幕/时间戳；不可把原素材 ASR 时间直接用到重排后的成片。没有可信映射时在最终人声轨重新识别。

## 实现方式

建议先验证现有本地 Web 管理端 + 编辑页面 + 本地媒体服务 + FFmpeg 导出。编辑页面负责时间线交互、项目状态与基础合成；本地服务负责媒体读取、缩略图、波形、代理视频、字幕、人声文件及导出任务。

FFmpeg 可以用于导出，但不是现成的交互式剪辑播放引擎。浏览器播放多个片段/轨道的切换、缓冲、音画同步和效果合成需要单独实现与测试。第一步用真实素材验证跨片段播放、多轨音频和字幕效果；无法稳定达到要求时评估 MLT 原生播放/渲染内核及桌面壳，避免在未验证时锁死架构。

原片用于最终渲染，必要时生成代理视频供预览。项目中间音频用无损缓存，最终导出按需 AAC 编码；只有纯画面后处理且音轨满足封装要求时才考虑音频直接复制，实际剪辑/混音/变速需要重新编码。

预览与导出共享同一份时间线、字体文件、资源版本和效果参数；复杂效果支持短段渲染预览。共享参数不自动保证像素一致，必须用真实导出验证。第一版限制支持的模板范围，对不支持的效果明确提示。

## 资源与技术来源

### 转场

大多数基础转场由代码生成，不需要下载素材。FFmpeg xfade 提供叠化、擦除、滑动、缩放等；音频可用 acrossfade。后续可评估 MLT/frei0r；具体 Windows 构建是否带插件必须检测。

官方资料：https://ffmpeg.org/ffmpeg-filters.html#xfade 、https://www.mltframework.org/plugins/PluginsTransitions/

### 特效与动画

亮度、对比度、饱和度、模糊、裁剪、旋转等采用 FFmpeg 滤镜。放大、淡入、位置移动等通过关键帧参数与插值实现。复杂视觉特效另做合成或插件适配，不能默认导入任意剪映特效包。

滤镜资料：https://ffmpeg.org/ffmpeg-filters.html

### 贴纸

先内置自制的箭头、边框、角标和装饰，并支持用户导入具有使用权限的 PNG/WebP/GIF/透明视频。动态素材导入时生成统一动画缓存用于预览和导出；GIF 的透明与色彩限制需处理，不保证任何 GIF 都有平滑透明边缘。

LottieFiles 可作为动画素材来源；lottie-web 是播放组件，两者不是同一类资源。Lottie 渲染支持需要适配，不能直接把任意 Lottie JSON 交给 FFmpeg。社区动画逐项确认授权；用于合成成片与随软件分发独立素材包是不同用途，不默认整库打包。

官方资料：https://github.com/airbnb/lottie-web 、https://help.lottiefiles.com/animation-licensing-basics-

### 字幕

识别复用现有 ASR 或 faster-whisper；词级时间戳是识别估计，需要人工调时能力。渲染采用 ASS/libass 处理基础样式及其支持的动画；复杂逐字弹跳/多层图文组合需要自定义渲染。

模板自己定义字体、字号、描边、阴影、颜色、位置、行宽/行数、断句规则、关键词样式及动画。建议起步 6 套：白字黑边、黄白强调、半透明底条、简洁细字、粗体标题、逐字高亮。不同动画模板有不同实现成本；先做真实样张验收。

字体优先思源黑体等明确开放的字体；导入字体时保留许可证和来源。模板应使用固定字体文件，不能只按系统字体名匹配。

资料：https://github.com/SYSTRAN/faster-whisper 、https://github.com/libass/libass 、https://github.com/adobe-fonts/source-han-sans

### 音频

本地导入已有授权的音乐/音效，软件管理试听、收藏、分类、裁剪、音量和循环。外部候选来源为 Pixabay Music 或明确覆盖目标用途的购买/委托素材。Pixabay 不允许将素材作为独立内容重新分发；不能把网站资源默认打包成软件音乐库。用于带货/广告的范围以实际资源许可为准，平台内可用不自动等于可导出到其他工具使用。

如需使用平台内音乐，可把在发布平台添加音乐保留为工作流选项，而不是要求编辑器复制整个平台曲库。

资料：https://pixabay.com/music/ 、https://pixabay.com/service/license-summary/ 、https://pixabay.com/service/terms/

人声处理采用独立缓存与准确时间映射；原声与人声轨互斥选择，不能意外同时叠加。Demucs 等模型可用于后续独立处理，但不承诺完美分离。V1 草稿音频问题另见本目录的备忘录。

## 素材库形态

本地资源库包含 fonts、stickers、music、sound_effects、subtitle_templates、transition_presets、effect_presets、postprocess_templates。每项保存唯一 ID、版本、缩略图/试听、来源、作者与许可记录；用户导入资源可复制到受管目录或保留引用并记录指纹。模板与素材分离，换素材无需修改程序。

自制素材或允许软件再分发的资源可以内置；只允许用于合成作品的资源作为用户本地导入。第一版不做在线素材商城或自动爬取。

## 后处理要求

按用户习惯，画中画不透明度默认 1%，素材音频关闭，贴纸绝大部分置于画布外仅露角落。进度条如需完全不盖原画面，使用独立预留区域，需要接受输出布局变化；否则是明确的贴边覆盖。

不承诺此类视觉变化影响平台重复内容判定。预览和导出都需要检查主体、字幕是否受到影响。

## 验证顺序

1. 先用真实粗筛素材做多轨、切点、音频与 6 套字幕的短段原型，确定性能与质量是否可接受。
2. 完成多时间线、撤销保存、素材重连、普通/波纹删除和导出队列。
3. 扩充贴纸、基础转场/特效、音乐混音与后处理模板。
4. 人声来源映射修复另行进行；独立分离模型和复杂字幕动画在质量验证后扩展。

不提供未经实测的工期、实时性能或与剪映完全等效的承诺。当前交付为研究方案和音频问题备忘录。
