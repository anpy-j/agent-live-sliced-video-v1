# V1 S4 口头词清理

在“规则管理 → 口头词清理”人工输入无声调拼音，音节用空格分隔，例如 `wo gao su ni`、`qi shi`、`er qie`、`zhen de`。每条规则选择清理范围“句首”或“全部”。支持备注、编辑、启用、停用和删除。没有内置自动启用的规则，数据保存在当前应用数据目录的 `data/filler_rules.json`。已有中文规则读取时自动转换为拼音，保留 ID、备注和启停状态；缺少范围的旧规则按“全部”处理。

V1 S4 流程开关开启时，保存后在下次执行 V1 S4 时生效。开关关闭时仅保留试匹配，不参与 S4 清理。详见 [V1 规则流程开关](rule-pipeline.md)。S4 完成编排后，将每个入选片段的全文转换为拼音，用与 S2 拼音规则相同的连续音节算法匹配。扫描全部位置，原文和字符位置保留。清理范围决定实际清理哪些命中：“全部”清理片段中每一个可对齐命中；“句首”只清理片段文本开头（命中的口头词前面仅有标点或空白）的命中，句中、句尾命中保留并记录原因。例如 `zhen de` 同时命中“真的”和“真得”；“你这样穿真的显瘦”在“全部”下预览为“你这样穿显瘦”，在“句首”下因为没有句首命中而保持原文。重叠命中合并删除区间，跨标点可连续匹配，数字或英文会打断连续拼音。配置的拼音按全文字面执行，不区分强调词与正文含义。

文字与音视频使用同一份清理结果。先检查命中起止位置与 ASR 词块边界是否对齐，生成词级候选切点；有时间戳不等于切点精确，实际清理还需通过下述音频复核。句中命中会将原入选片段拆成多个保留区间并拼接；同一 ID 的保留区间在分段导出时仍合并为一个完整交付片段。词块内含有口头词和正文、缺少时间戳、词文无法对齐、边界重叠时，该命中保留并记录原因；同一句内其他可对齐命中仍会清理。清理后没有正文时保留原片段。不会按字数估算时间。

新 V1 S1 在 `clauses.json` 保存词级数据，随 S1 快照缓存复用；旧任务也可以读取已有 `words.json`。缺少词级数据的旧任务会跳过实际剪切，可重新执行 S1 获取词级数据后再执行后续阶段。

S4 将原始入选候选、清理后候选、所有拼音命中、删除区间、保留区间和规则快照写入 `order.json` 的 `filler_cleanup`，并更新 `total_seconds`。清理会减少时长，沿用实际剩余时长出片。`manifest.json` 记录同一份报告。只重渲染会复用已保存切点；修改规则后，需要重新执行 S4 才会生效。没有清理快照的历史编排沿用原剪切行为。

测试区支持：

- 输入文本：展示原文拼音、命中原文及字符位置和清理预览，不验证音视频切点。
- 已完成 V1 任务：读取 S4 入选片段、当前规则与 S1 词级数据，显示原文、实际清理结果、区间、减少秒数及跳过原因；测试不写回任务或成片。
- 选择单条规则：可测试已停用规则，不会启用生产规则。默认测试全部启用规则。

## 统一音频边界校准

V1 S4 和测试列表的单句渲染共用 `agent_video/filler_audio.py`。每个命中语句的每个保留区间单独检查，不会为一次单句测试处理任务的其他语句。文字试测、任务列表试测仍快速展示候选切点，音频复核在点击渲染后后台执行。

1. 使用与渲染器相同的原素材映射、倍速、帧时长取整、12ms 边缘淡化和 AAC 编码，生成短音频探针。音视频一起使用校准后的切点。
2. 用本地 ASR 在不提供目标文本提示的情况下重新识别，按完整无声调拼音序列核对正文，忽略标点与繁简差异。正文中间不一致或缺字时保留原句，不以裁剪修复。
3. 若正文完整但开头/结尾还有多余音节，只调整本次删除产生的交界。以 20ms 为步长寻找最小通过切点；每侧最多 240ms，并且边缘词块至少保留 100ms。句首、句中、句尾的每次命中均采用同一规则，没有针对“所以”的硬编码偏移。
4. 无法在保护范围内通过复核、缺少本地模型或提取失败时，S4 保留该候选原句并记录原因；单句预览显示失败，不提供未经复核的文件。
5. 单句视频导出后再识别实际 AAC 音频，全部分段通过后才允许播放和下载。模型识别仍可能出错，复核通过表示自动检查一致，不代表保证音素边界绝对精确。

校准报告写入 `filler_cleanup.rows[].audio_verification`，保留原切点、逐次尝试、识别文本、最终区间及跳过原因，更新总时长和摘要。重新渲染沿用已保存的校准快照；已有成片不会自动变化。要让已有任务采用新流程，需要重新执行 S4。测试列表重新点击单句渲染即可使用新流程。

复核模型只读本地文件，不自动下载。可用环境变量 `LIVECUT_FILLER_VERIFY_MODEL` 指定本地 Paraformer 或 CTranslate2 Whisper 模型目录。自动发现现有 `HF_HOME` / `MODELSCOPE_CACHE` 同级 `asr/funasr-paraformer-zh/speech_paraformer-large_asr_nat-zh-cn-16k-common-vocab8404-pytorch` 目录；否则使用 `DOUYIN_WHISPER_MODEL` 或缓存的 `small` 模型。需要对应的 `funasr` 或 `faster-whisper` 依赖。首次载入模型较慢，后续复用同一实例。
