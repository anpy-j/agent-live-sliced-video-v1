# LiveCut 0.2.2 跨轨拖动修复

构建源码：`11d7cafb3a3d16285170b46548f990eda6d604c3`。

原来的片段拖动只修改横向时间位置，未修改所属轨道。本版支持把片段上下拖到其他同类型、未锁定的轨道，保留片段 ID、素材范围与属性，并作为一次编辑记录，支持撤销、重做和保存。拖到锁定轨道、不同类型轨道或轨道外时恢复原位置；修剪边缘仍只调整原轨道内的素材范围。

另修复较矮桌面窗口中，选中片段展开属性面板使时间线位置发生变化的问题：拖动期间暂缓刷新属性面板，松开后再刷新。
