# V1 完整性排查与修复

在候选剔除边界修复之后，继续检查时间轴、缓存、文件写入和任务控制。不改动主观编排策略，不调用真实 AI，不修改历史成片或用户素材。

## 音频与时间轴

此前虚拟时间线逐段提取音频后直接拼接，没有校验时间线空档或重叠；倍速处理后也没有将每段音频精确限制到目标采样数。这可能令后续 ASR 时间偏离视频位置。小于 10ms 的素材片段还会被跳过，造成累计偏移。

现对连续主视频轨道校验时间、倍速及源/目标时长。无法可靠映射的空档、重叠、异常倍速会明确报错，要求整理草稿，不自动猜测画面。每段音频按绝对时间轴边界折算 16kHz 样本数，重采样、补齐尾部并精确截断后拼接，验证完整 WAV 的格式、样本数及末尾数据。低于采样精度的区间报错，不静默略过。0.25 倍等慢速使用兼容的多段 atempo。

V1 渲染逐候选检查映射是否完整。一个候选全部或部分落在素材之外时停止，不再只渲染成功映射的部分；合法跨源、跨倍速映射仍可正常使用。

## 缓存

- 音频缓存绑定源文件路径、大小和修改时间，使用前验证 WAV 没有损坏或截断。新 WAV 完整验证后才替换旧文件。
- V1 共享 S1 指纹包含识别模型、后端、批处理配置及术语纠错代码；S1 契约升级使旧时间基准结果重新生成。
- V1 单素材 S1 缓存此前只核对路径字符串。现绑定素材指纹、识别配置和切分参数，并验证原始 S1 数据摘要。优先读取 `clauses.json`，不把 S2/S3/S4 修改过的工作时间线当作纯 S1。旧的未验证单素材缓存需重新识别一次。
- 语义归组缓存增加提供方、引擎、API 地址和备用模型配置指纹，避免切换模型服务后仍复用旧分组。配置中不记录 API 密钥。

## 写入、取消和重跑

- V1 阶段 JSON 改为先写临时文件再原子替换。中途写入失败仍保留上一份完整数据，界面读取不到半截 JSON。
- 旧工作进程仍在保存时，不允许同一任务重跑并同时写工作目录；适用于运行、暂停中及尚未结束保存的暂停任务。
- 分段导出间检查取消请求。交付收尾和单节点向后推进也检查取消状态，防止取消后继续编码全部片段、自动执行下游、把任务标为完成或增加产出次数。

## 验证

新增 `tests/test_v1_integrity.py`，覆盖真实 WAV 倍速拼接、极短片段、引号路径、缓存更新和截断、部分映射、原子写入失败、同名素材替换、识别配置变化、暂停重跑竞争和导出途中取消。新增语义归组提供方/API 地址缓存失效回归。更新旧测试中的模拟音频和几何数据，使其满足实际产物契约。

不支持的时间线现在提前失败，不再以看似成功的结果掩盖时间偏移；这不代表需要改变合法时间线或默认打开额外 AI 节点。
