## 后续依据

1. 不将本轮新 S3 直接替换旧版。恢复有用半句和严格淘汰混杂垃圾需分别验证，不能靠扩大规则把候选删到不足。
2. 跨位置组合需要携带原文明确的对象、条件和比较基准；未明确的指代标为未知，不凭视觉或代词猜测。脚本可拦截明确冲突，不能证明未知语义正确。
3. 保留完整表达组及真实源区间；精确重复与高置信催拍规则可辅助筛掉，同义重复和表达完整性仍需内容复核。
4. 约120秒达标与文本合格分别验收；不以重复填充时长，也不把短输出自动当成功。
