## 后续修复依据

1. 四项结构补丁无法独自解决语义筛选失败，不能以结构检查替代内容验收。
2. S4 要把完整性、混杂话术和有效信息作为选择门槛，不能只按卖点词或逐条摘要选择。
3. 对候选总时长不足的任务，应明确报告不足；需要检查 S2/S3 丢失的有效上下文，不能让 S4 凑垃圾。
4. 原版依赖上下文仍需真实样本检查；模型调用一次并不等于低 token，用量按各 result.json 的供应商返回值记录。
