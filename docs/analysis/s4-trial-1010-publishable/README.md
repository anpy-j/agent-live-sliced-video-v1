## 输入与限制

五份候选总时长都超过120秒，但候选并不代表全部有效；不能仅据候选总量证明必能做出120秒合格成片。用户人工处理后能发布的事实说明素材本身有利用价值，程序输出仍需独立验收。

[前序筛选抽查](upstream-audit.json)记录 S2/S3 保留数量和有限剔除样例；这是抽查，不能作为全部前序筛选无误的证明。

用量采用供应商返回值，包含调用通道自身开销，不能把输入字符数当作计费 token，也不能把输出 token 全视为最终 JSON 的长度。
