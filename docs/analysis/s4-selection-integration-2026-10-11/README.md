# 新版 S4 接入记录

S4 每份素材一次模型调用，输入全部 S3 初筛候选的 `id/text/seconds/context`；不附带 S3 理由、源文件元数据或历史对话。输出仍沿用 `main_product/sections/ordered_ids`，每个 section 表示完整表达或必要句群，同一角色可以出现多次。

候选不预先合并。S4 重新精选，删除混杂闲聊、空泛指令、动作预告和无信息转场；原版介绍及其依赖表达禁止入选。搭配句须有具体方式、效果或条件，不禁“西装裤、牛仔裤”等商品名。不根据模糊代词猜测商品归属，不限定固定卖点段数，不要求短素材全选。

程序在 `order.json` 保存 `selection_version=2` 和 `selected_clauses`。只将同一句群中原始相邻、时间完全连续的入选子句合并；其余分别剪切。重渲染校验快照并复用入选区间，不再从删去淘汰句后的列表重新聚合。上游变化或 ID 失配会明确要求重跑 S4。

旧版计划读取时保留淘汰句断点，不静默忽略失配 ID。原版硬禁沿用统一词表，S4 候选和渲染前再次校验。

## 使用

新任务自动使用新版 S4。已有任务在任务详情重新执行 S4，复用已有 S3 结果并继续渲染。仅重渲染旧任务不会调用新版 S4 重新选句。
